# Custom Themes Collection

A collection of customized themes.

## Themes

- [jetbrains-flexppuccin](./jetbrains-flexppuccin): Flexppuccin, a Catppuccin Latte variant for JetBrains IDEs, customized with warm Flexoki Light paper background tones instead of the default cool blue.
- [vscode-flexoki-light-mikusr](./vscode-flexoki-light-mikusr): Flexoki Light theme for Visual Studio Code, extracted from one-hunter.
