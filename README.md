# Custom Themes Collection

A collection of customized themes.

## Themes

- [jetbrains-flexppuccin](./jetbrains-flexppuccin): Flexppuccin, a Catppuccin Latte variant for JetBrains IDEs, customized with warm Flexoki Light paper background tones instead of the default cool blue.
- [vscode-flexppuccin](./vscode-flexppuccin): Flexppuccin ported to Visual Studio Code, generated from Catppuccin Latte with the same Flexoki Light paper and ink tones.
- [vscode-flexoki-light-mikusr](./vscode-flexoki-light-mikusr): Flexoki Light theme for Visual Studio Code, extracted from one-hunter.

## Prebuilt Packages

Ready-to-install packages are committed to the repo:

- JetBrains: [`jetbrains-flexppuccin/dist/Flexppuccin.jar`](./jetbrains-flexppuccin/dist/Flexppuccin.jar)
- VS Code: [`vscode-flexppuccin/dist/flexppuccin-1.0.0.vsix`](./vscode-flexppuccin/dist/flexppuccin-1.0.0.vsix)

The same files are attached to the [GitHub releases](https://github.com/MikusR/themes/releases).
